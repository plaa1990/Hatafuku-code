Hatafuku Studio Commercial Pro - Standalone Suite
===================================================
1. แตกไฟล์ zip นี้ลงในเครื่อง / Extract all files
2. ดับเบิ้ลคลิกหรือเปิด index.html (หรือ standalone-index.html) ในเว็บเบราว์เซอร์
3. สำหรับ Creator Studio Pro สามารถเปิด creator-studio.html ได้โดยตรงหรือผ่านหน้าหลัก
4. ทำงานออฟไลน์ 100% ไม่ต้องใช้อินเทอร์เน็ต รองรับทั้งมือถือ Android, iOS, แท็บเล็ต และคอมพิวเตอร์
